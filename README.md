# WhatsApp Chat CRUD App

A simple WhatsApp-style chat application built using Express.js, MongoDB, Mongoose, and EJS.

## Features

- View all chats
- Create new chat
- Edit existing chat
- Delete chat
- Delete confirmation popup
- MongoDB database integration
- RESTful routes using Express

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- CSS
- Method Override

## Installation

Clone the repository:

bash
git clone https://github.com/ajalkarsiddhi-code/whatsapp-chat-crud.git


Install dependencies:

bash
npm install


Run the application:

bash
node index.js


Open:


http://localhost:8080/chats
